# Rank art v5, refinement pass, ChatGPT prompts

These are the 5 corrected prompts for the rank emblems that need a second take (`kohai`, `volume-keeper`,
`guild-senpai`, `first-print-hunter`, `guild-legend`). The Codex image-generation quota ran out before
this refinement pass could render, so the owner is generating these 5 directly in ChatGPT instead.

The other 5 ranks in the set (`preorder-hunter`, `limited-run-curator`, `club-sensei`,
`rare-edition-archivist`, `collection-shisho`) already came out right in take 1 and do not need to be
regenerated.

## Instructions for the owner

1. Generate the 5 prompts **one at a time**, in separate messages, not all at once. Each is a full
   self-contained brief for a single image.
2. Copy each prompt exactly as written, including the "never include" list at the end.
3. If ChatGPT gives you a **transparent PNG**, that is the ideal result, use it as is.
4. If ChatGPT cannot give you transparency and instead returns a **flat, uniform white (or plain
   colour) background**, that is fine too. Do not try to fix it yourself. Just tell us which ones came
   back with a background, we will crop the alpha channel back in on our end.
5. Send back the PNG files exactly as ChatGPT gives them to you, no cropping, no resizing, no
   re-exporting.
6. If a result looks visibly wrong (extra objects, text baked into the image, cut off edges), it is
   fine to ask ChatGPT to retry the same prompt before sending it over.
